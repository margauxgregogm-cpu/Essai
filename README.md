# Beauty Fidelity — Locked-on Scroll

Aucune dépendance (pas de GSAP, pas d'Internet requis).

## Tester
```
cd Essai && python3 -m http.server 8000
```
Ordinateur : http://localhost:8000 (Chrome, Safari).
iPhone : même Wi-Fi, ouvrir http://<IP-de-l-ordinateur>:8000 dans Safari.

## Images (remplacer sans toucher au code)
- `assets/cards/{matcha,vanille,beaute,luxe,floral}.png` — PNG transparent, ratio libre (respecté), ≥1200 px de large.
- `assets/backgrounds/{matcha,vanille,beaute,luxe,floral}.jpg` — JPG 2400×3000 px min (cadrage centré, sujet au centre, compatible portrait/paysage), < 600 Ko.
